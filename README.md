A tiny program that writes one original pickup line (a single sentence of at most 200 characters) to `/output/entry.txt` for make.fun's "The Perfect Pickup Line" bounty.

## The line

> I trained on a million conversations, but none of them taught me what to say when you walked in.

## Run it

```sh
python3 main.py
```
